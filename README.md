# LaundryWatch

A local-first web app that tells you whether a washer or dryer is running,
driven by a taped-on vibration sensor and a learned model of what each phase
of a cycle looks like in the frequency domain.

Runs entirely on your own machine -- no cloud, no hosting. See
[CLAUDE.md](./CLAUDE.md) for the full build plan and repo map.

> Scaffolded, not built. Code is written function-by-function.
